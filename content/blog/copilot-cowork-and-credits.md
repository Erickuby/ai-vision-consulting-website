# Copilot Cowork and Credits: What Agentic Work Costs and How to Control It

Most AI tooling gives you a draft and leaves the finishing to you. Copilot Cowork is built on a different promise: you define the work, it runs the work, and what comes back is meant to be done rather than started. That is a genuinely different product, and it comes with a genuinely different bill. Cowork is charged by usage rather than per seat, so understanding the cost model matters before anyone in your organisation gets enthusiastic.

## Quick answer

Cowork is an agentic system in Microsoft 365 that plans, executes and delivers multi step work across your apps, files and data. It became generally available in June 2026. Rather than answering inside one document, it coordinates longer tasks that span Outlook, Word, Excel and PowerPoint, using context from your emails, meetings and files.

It is billed with Copilot Credits, a pooled currency that meters AI usage across Copilot services and agents. Under pay as you go pricing one credit is one US cent. What a task costs depends on four things: the model used, how much context had to be retrieved, how many tool actions were taken, and how long it ran. A light task lands under two dollars. A heavy one can pass fifteen.

Administrators get a Cost Management Dashboard in the Microsoft 365 admin centre for monitoring usage, setting budgets and controlling spend. Use it before you need it.

## Key takeaways

- Cowork completes tasks rather than producing drafts for you to finish.
- It works across apps and data, not inside a single file.
- Billing is usage based through Copilot Credits, not a flat per person fee.
- Cost scales with task difficulty, so vague requests are expensive requests.
- Set budgets and monitor the dashboard from day one, not after the first invoice.
- The economics work when the task would otherwise cost real staff hours.
- Anything with a legal, financial or customer consequence still needs a human sign off.

## What Cowork actually does

### The difference from Agent Mode

Agent Mode in Word, Excel and PowerPoint works inside the file you have open. Cowork operates a level above that. It handles work that crosses boundaries: reading a thread of emails, pulling figures from a spreadsheet, drafting a document and assembling a deck, as one continuous piece of work with a deliverable at the end.

The practical test is whether the task involves several applications and a sequence of dependent steps. If yes, that is Cowork territory. If it is one document and one goal, Agent Mode is cheaper and faster.

### The kind of task it suits

Think of the jobs that currently occupy a capable person for two hours and involve no genuine judgement, only assembly. Preparing a client review pack from the last quarter of correspondence and performance data. Turning a long meeting series into a structured project summary with actions. Building a monthly reporting bundle that pulls from four places and always looks the same.

These are tasks where the standard is objective, the inputs are already in Microsoft 365, and the work is tedious rather than difficult. That combination is where usage based pricing makes obvious sense.

### The kind of task it does not suit

Anything where the requirement is unclear at the start. Cowork will run the task, consume credits and deliver something confident that answers the wrong question. Ambiguity that costs you nothing in a chat window costs real money here.

Also avoid it for work with a genuine judgement core: deciding a strategy, handling a sensitive personnel matter, choosing between two commercial options. It can assemble the evidence for those. It should not be making the call.

## How the money works

Credits are consumed according to four inputs: the model, the context retrieved, the tool calls made, and the runtime. That is worth understanding because it tells you exactly which behaviours are expensive.

| Cost driver | What increases it | How to keep it down |
| --- | --- | --- |
| Model use | Longer, more complex reasoning | Scope the task tightly |
| Context retrieval | Searching wide across mail and files | Point it at specific sources |
| Tool calls | Many separate actions and apps | Break huge tasks into defined pieces |
| Runtime | Long running, open ended work | Define what finished looks like |

The pattern is consistent: precision is cheap and vagueness is expensive. A well specified task that names its sources and its output format will cost a fraction of the same request phrased loosely, and produce better work.

### Working out whether it is worth it

The arithmetic is refreshingly simple. Take the task, estimate the staff time it currently consumes, and apply a realistic hourly cost. Compare that with the credit cost of the run plus the time someone spends reviewing the output.

A task that takes a person ninety minutes at a loaded cost of thirty pounds an hour is roughly forty five pounds of time. If Cowork completes it for a few pounds of credits and fifteen minutes of review, the case makes itself. If the task takes ten minutes by hand, it never will.

Run that sum for three or four candidate tasks before you commit to anything. It filters out most of the ideas that sound impressive and save nothing.

## Keeping the spend predictable

**Turn on budgets before you turn on enthusiasm.** The Cost Management Dashboard exists for exactly this. Set a limit that reflects what you actually intend to spend this quarter, not what you could tolerate losing.

**Name who can run Cowork tasks.** Usage based billing plus unrestricted access is how organisations get surprised. Start with a small group who understand the cost model.

**Log what you run and what it cost.** After a month you will know which task types justify themselves. Without a log you will only know the total, which tells you nothing actionable.

**Review the first outputs closely.** Early on, the review is not only quality control. It is how you learn to specify tasks well, which is the main lever on cost.

**Revisit anything that runs repeatedly.** A task you run weekly is worth spending an hour refining. Small improvements to a recurring request compound.

## Where this sits in a sensible AI plan

Cowork is not the starting point. Organisations that get value from it have usually already done the unglamorous work: their people know how to use Copilot properly, their SharePoint permissions are not a liability, and they have identified which recurring tasks are genuinely worth automating.

Buying agentic capability before any of that is in place is the same mistake as buying Copilot licences and hoping adoption happens by itself. The tool is capable. The value comes from knowing precisely what you want it to do.

## Frequently asked questions

### Is Cowork included in a Microsoft 365 Copilot licence?

Cowork is enabled through usage based billing rather than being covered by a flat licence fee. That is the significant difference from the rest of Copilot, and it is why the admin controls and budgeting matter more here than elsewhere.

### What does a typical task actually cost?

It depends entirely on difficulty. Light tasks sit under a couple of dollars, heavier multi step work can exceed fifteen. Because pricing responds to model use, retrieval, tool calls and runtime, the same request phrased tightly or loosely can differ substantially in cost.

### Can we cap what a team spends?

Yes. The Cost Management Dashboard in the Microsoft 365 admin centre lets administrators monitor credit usage, manage budgets and control spend. Configure this before wider rollout rather than after.

### How is this different from building an automation in Power Automate?

Power Automate handles deterministic workflows: predictable triggers and fixed steps. Cowork handles work that needs interpretation and varies each time. Where a task is genuinely the same every run, a conventional automation is cheaper and more reliable.

### Should a small business be looking at this yet?

Only if there is a specific recurring task with real hours attached to it. For most small organisations the larger and cheaper win is still training people to use the Copilot they already have, and cleaning up the data it reads.
